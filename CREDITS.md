# Credits

Cadence builds on open work by other people. This file records what is used,
under which licence, and what was changed. Every new third-party source is
added here in the same change that adds it.

## Mouth map: the VocalTract package and Maeda's model

The side view of the mouth (`src/lib/platform/vocal-tract/`, copied to
`mobile/src/platform/vocal-tract/`) is a TypeScript port of the
[VocalTract LaTeX package](https://ctan.org/pkg/vocaltract) (release 1, 2012)
by Dimitrios Ververidis:

> D. Ververidis, D. Schneider and J. Koehler, "The vocal tract LaTeX package",
> *The PracTeX Journal*, 2012, no. 1.

- **Licence.** The package README licenses it under the
  [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0); the
  header of `VocalTract.sty` names the
  [LaTeX Project Public License](https://www.latex-project.org/lppl/). Both
  permit this translation. The attribution and modification notice is in
  [`NOTICE`](./NOTICE).
- **What was used.** The loading-factor table, the Maeda-to-drawing
  transforms, the static anatomy coordinates and the 26-phoneme German demo
  codebook, all from `VocalTract.sty` (SHA-256
  `98f51196590df349845f6cbdf06d375af4efa196dba46d321cb7516b2b61127c`, as
  shipped in TeX Live 2025).
- **What changed.** Translated from TeX to TypeScript; the drawing is cropped to
  the head and regrouped into named, highlightable layers; the front lip view,
  interpolation and the parameter fit are Cadence's own additions.
- **How it is checked.** `tests/platform/vocal-tract.test.ts` compares the
  port with coordinates computed by the original package
  (`tests/platform/fixtures/vocaltract-reference.json`, regenerated by
  `node scripts/vocal-tract/make-reference.mjs`).

The model's loadings are S. Maeda's: "Compensatory articulation during speech:
evidence from the analysis and synthesis of vocal-tract shapes using an
articulatory model", in W. J. Hardcastle and A. Marchal (eds.), *Speech
Production and Speech Modelling*, Kluwer, 1990.

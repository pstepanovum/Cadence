# Project Rubric

## 1. Interface Design (20 pts)
- Intuitive layout & navigation
- Visually appealing design
- Responsive (works on different screen sizes)
- Proper HTML structure (semantic tags)
- **Required:** Wireframes + User Flow explaining interactions

## 2. Express Basics (5 pts)
- Functional routes
- Middleware usage
- Proper server setup

## 3. App Deployment (5 pts)
- Successfully deployed on Render.com
- App runs without major issues

## 4. Database Integration (10 pts)
- Data is stored and retrieved correctly
- Persistent storage works reliably

## 5. Presentation of Data (20 pts)
- Data is clearly displayed
- Organized and easy to understand

## 6. Visualization (10 pts)
- Use of charts, graphs, or creative visuals
- Enhances understanding of data

## 7. Storytelling (10 pts)
- Clear concept and purpose
- Engaging explanation of the project

## 8. Innovation (5 pts)
- Creative features (e.g., gamification, personalization, unique visuals)

## 9. Originality (5 pts)
- Unique idea (not a basic or overused app)

## 10. Demo & Explanation (10 pts)
- Clear video presentation
- Explains design choices and development process

---
**Total: 100 pts**
